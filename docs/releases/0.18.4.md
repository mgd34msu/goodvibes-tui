# `0.18.4`

First full release of the TUI after the canonical SDK cutover.

## What Changed

### Canonical SDK Cutover

- Switched `goodvibes-tui` from the temporary beta line to the canonical `@pellux/goodvibes-sdk@0.18.14` package.
- Rewired the TUI to consume canonical SDK entrypoints instead of the temporary beta entrypoints.
- Removed duplicated local platform implementation that had already been extracted into the SDK, including large portions of contracts, daemon route handlers, runtime transports, state/runtime helpers, tools, utilities, and other shared platform code.
- Cut the remaining local state-inspector implementation over to the SDK-owned runtime inspection surface.

### CI And Release Path Fixes

- Fixed the eval gate to use the SDK-backed eval baseline, formatting, and scorecard exports after the local platform copies were removed.
- Fixed the performance gate to build CI snapshots against the SDK-backed `surfacePerf` shape instead of the pre-extraction local `uiPerf` shape.
- Fixed the architecture check so it tolerates removed migration targets on clean checkouts instead of crashing when extracted directories no longer exist.
- Fixed the release workflow so all release binaries build on `ubuntu-latest`, avoiding the earlier macOS runner cancellation that blocked release creation.
- Fixed the release workflow so manual reruns against an existing `v*` tag still execute the real release path instead of stopping at validation.
