# GoodVibes TUI 0.19.37

## Changes

- Updated `@pellux/goodvibes-sdk` to `0.25.14`.
- Regenerated foundation operator contract artifacts from the SDK 0.25.14 contract.
- Updated Home Assistant docs for the SDK-owned isolated remote-chat contract:
  responses use `mode: "remote-chat"`, return `assistant.text` and
  `assistant.speechText`, and do not include `agentId` for Assist chat.

## Notes

Home Assistant execution remains SDK-daemon owned. The TUI continues to own setup, settings, and credential entry; Home Assistant prompt ingress now runs through isolated daemon remote-chat sessions instead of any TUI/shared-session or agent execution path.
