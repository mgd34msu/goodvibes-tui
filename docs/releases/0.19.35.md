# GoodVibes TUI 0.19.35

This release updates the TUI to `@pellux/goodvibes-sdk@0.25.11` and wires the new SDK contract changes into onboarding, Cloudflare provisioning, auth-session display, and docs.

## Highlights

- Added Home Assistant as a selectable external surface in onboarding and Settings > Surfaces.
- Added Home Assistant setup fields for instance URL, access token, webhook secret, conversation id, daemon device metadata, event type, and per-surface auto-start.
- Expanded Cloudflare onboarding and `/cloudflare provision` to pass Tunnel token refs, Tunnel service URLs, Access app/service-token refs, and advanced resource fields through to SDK daemon routes.
- Updated auth-session display for the SDK's redacted session contract: session lists show fingerprints, and revoke-session accepts raw tokens or fingerprints.
- Regenerated foundation operator contract artifacts from SDK `0.25.11`.

## Behavior

Cloudflare and Home Assistant remain opt-in. Home Assistant setup values can be saved without auto-starting the surface. Cloudflare provisioning still routes through SDK daemon APIs; the TUI does not call Cloudflare APIs directly.
