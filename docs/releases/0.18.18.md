# 0.18.18: TUI render performance, coalescing, dirty-flag, buffer reuse

**Released**: 2026-04-16
**Type**: Performance (no user-facing behavior change)

## Summary

Three highest-impact per-frame waste eliminators from the deep render-path review. Combined they cover virtually all CPU cost incurred during streaming output:

1. **R1, render coalescing**: a burst of N `requestRender()` calls in one microtask now produces exactly one render pass, not N.
2. **R2, panel dirty-flag activation**: panels that haven’t changed between frames are no longer re-rendered. The existing `needsRender` contract was in place but dead. This commit activates it.
3. **R3, buffer reuse**: the `TerminalBuffer` constructor and `clone()` call that fired every frame are eliminated via double-buffer swap. GC pressure per keystroke/token drops significantly.

## What changed

### R1: Render coalescing (`src/runtime/bootstrap-core.ts`)

`requestRender()` is now wrapped in a `setImmediate`-based coalescer. A `scheduled` flag prevents duplicate queuing. A 16ms minimum-interval gate caps rendering at ~60fps during streaming bursts.

### R2: Panel dirty-flag activation

- `src/panels/types.ts`: `Panel` interface gains `invalidate(): void` and `markRendered(): void`.
- `src/panels/base-panel.ts`: `BasePanel` implements both. `invalidate()` sets `needsRender = true`; `markRendered()` clears it.
- `src/renderer/panel-composite.ts`: direct `panel.render(w, h)` calls replaced by `renderPanel(panel, w, h)`, a local helper backed by a `WeakMap<Panel, {lines, width, height}>` cache. Skips re-render when `!panel.needsRender && dims unchanged`. Calls `panel.markRendered()` after each actual render.
- **Audit result**: all 40+ panels that write `needsRender = true` on state mutation are compatible. `ScrollableListPanel` (10 write sites, one clear site at top of `render()`) already clears the flag correctly inside its own `render()`. The new `markRendered()` call in `renderPanel()` is a no-op in that case (already false). No panels were found that mutate state without setting the dirty flag.

### R3: Buffer reuse (`src/renderer/buffer.ts`, `src/renderer/compositor.ts`)

- `TerminalBuffer.reset(w, h)`: overwrites cells in-place; reallocates only when dimensions change.
- `Compositor` now holds `frontBuffer` and `backBuffer` (both long-lived). Each `composite()` resets back, composites into it, diffs against front, writes diff, swaps. No `new TerminalBuffer(...)` after session start; no `clone()` ever.

### Tests

- `src/test/renderer/render-perf.test.ts` (new, 10 tests): R1 coalescer, R2 dirty-flag skip/invalidate/markRendered, R3 `TerminalBuffer.reset()`.
- `src/test/renderer/compositor.test.ts` (extended, 3 new tests): double-buffer reuse, `resetDiff()` clearing both buffers, resize handling.
- Mock `Panel` objects in 4 test files updated to implement `invalidate()`/`markRendered()`.

## Verification

- `bun run test`: 438 test files, all pass
- `bunx tsc --noEmit`: clean
- `bun run architecture:check`: passes

## Migration

Panel authors: if you implement `Panel` directly (not via `BasePanel`), add:

```ts
invalidate(): void { this.needsRender = true; }
markRendered(): void { this.needsRender = false; }
```

All `BasePanel` subclasses inherit these for free.
