# GoodVibes TUI 0.19.34

This release updates the TUI to `@pellux/goodvibes-sdk@0.25.10` and wires the SDK-owned Cloudflare control-plane routes into onboarding, settings, and slash commands.

## Highlights

- Added optional Cloudflare onboarding for Workers/Queues batch processing and advanced Tunnel, Access, DNS, KV, Durable Objects, Secrets Store, and R2 components.
- Added `/cloudflare` and `/cf` commands for status, token requirements, bootstrap-token operational-token creation, discovery, validation, provisioning, verification, disable, and onboarding entry.
- Added a Cloudflare settings category that groups `cloudflare.*` and `batch.*` config keys.
- Added Cloudflare setup docs covering batch modes, token paths, daemon routes, and GoodVibes secret references.

## Behavior

Cloudflare is still opt-in. Local immediate daemon behavior remains the default unless Cloudflare is enabled and a non-`off` batch mode is selected.

Optional Cloudflare provisioning failures are reported as warnings during final onboarding apply. Settings are still saved so users can continue using the local TUI/daemon and retry Cloudflare setup later.
