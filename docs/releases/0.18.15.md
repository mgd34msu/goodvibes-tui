# GoodVibes TUI 0.18.15 Release Notes

**Date**: 2026-04-16

## Summary

Wave 1 correctness fix plus six dead-code/consolidation cleanups targeting daemon shutdown safety and SDK mirror file removal.

## Correctness Fix

**Daemon SIGINT/SIGTERM drain with 15-second timeout** (`src/daemon/cli.ts`)

- Added `AbortController` so in-flight request handlers receive an abort signal on shutdown
- Wrapped `facade.stop()` in `Promise.race` with a 15-second deadline
- On timeout, logs `WARN: shutdown deadline exceeded` and calls `process.exit(1)` to force-kill
- Added `shutdownInFlight` guard to debounce rapid double-signal (prevents double-shutdown race)

Previously, a hung service would wedge the daemon process indefinitely on Ctrl-C.

## Dead Code Removal

Removed 15 TUI-local files that were either dead or pure re-exports with zero external importers:

- `src/runtime/diagnostics/index.ts`, `provider.ts`, `actions.ts`
- `src/runtime/diagnostics/panels/agents.ts`, `events.ts`, `health.ts`, `tasks.ts`, `tool-calls.ts`
- `src/runtime/store/helpers/reducers.ts` (31-line barrel re-export)
- `src/runtime/store/helpers/reducers/shared.ts`, `sync.ts`, `lifecycle.ts`, `conversation.ts`
- `src/runtime/store/domains/permissions.ts`, `conversation.ts`

All call sites already imported from `@pellux/goodvibes-sdk` directly. Updated `src/runtime/diagnostics/panels/index.ts` to re-export the panel classes from SDK.

## Config Shim Inlining

Deleted two 1-line SDK re-export shims and updated all 29 importers to reference the SDK directly:

- `src/config/service-registry.ts` (27 importers + 2 bootstrap inline-imports)
- `src/config/subscription-providers.ts` (8 importers)

## SDK Consolidation

Converted 9 TUI mirror files to 1-line SDK re-exports, eliminating ~400 lines of maintained-in-parallel code:

- `src/runtime/ui-events.ts`
- `src/runtime/ui-service-queries.ts`
- `src/runtime/ui-read-model-helpers.ts`
- `src/runtime/ui-read-models-observability.ts`
- `src/runtime/ui-read-models-observability-maintenance.ts`
- `src/runtime/ui-read-models-observability-options.ts`
- `src/runtime/ui-read-models-observability-remote.ts`
- `src/runtime/ui-read-models-observability-security.ts`
- `src/runtime/ui-read-models-observability-system.ts`

All existing call-site import paths preserved (no call-site edits required).

## Skipped / Deferred

- `src/runtime/ui-services.ts`: imports TUI `SecretsManager` subclass; cannot be replaced without losing the `surfaceRoot: 'tui'` injection
- `src/runtime/ui-read-models.ts`: depends on TUI `RuntimeServices` type; would require type compatibility verification before SDK consolidation
- `src/runtime/diagnostics/panels/panel-resources.ts`: TUI version (119 lines) uses `ComponentHealthMonitor` from `panel-health-monitor.ts`; SDK version (152 lines) uses `component-health-monitor.js` — different monitor interfaces, TUI-specific binding retained
