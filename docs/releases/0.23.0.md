# GoodVibes TUI 0.23.0

Third best-in-class program release: provider failover on the turn path, the context/compaction surface completed, the E20 export track closed, and the renderer pinned by golden frames.

## Changes

- **Turn-path provider failover**: when a turn fails with a provider error, the runtime walks the configured fallback chain with bounded same-turn retries. A per-turn visited set prevents billable A-to-B-to-A loops, a message-count snapshot with rollback prevents duplicate user messages, synthetic models are never failed into (a synthetic model is itself a fallback ladder), and retries preserve the original message content and options.

- **`/compact` preview and after-notice**: before compaction runs, the transcript shows a clearly labelled estimate (current tokens, message count, estimated result). When compaction completes, a notice shows the real before/after message and token figures from the compaction event.

- **`/compact-history`**: lists past compaction events with trigger, message, and token deltas. Restore is list-only until the SDK exposes a snapshot/restore API, and the output says so plainly.

- **`/keep`**: pins text into session memory. Pinned entries flow into the compaction handoff on both manual and auto-compact paths. Wording is honest: pinned text survives the next compaction, and session memories are in-memory only (cleared on restart). Named `/keep` because `/pin` belongs to model favorites.

- **`/channel` command**: operator visibility into the omnichannel substrate.
  - `/channel` (no args) / `/channel panel` opens the Routes panel.
  - `/channel status` builds a full integration review (routes, delivery, sessions, tasks, pending approvals).
  - `/channel routes` prints the raw route binding snapshot.
  - `/channel delivery` prints per-route delivery counts and last-error state.
  - `/channel policy` prints configured channel surfaces (enabled/disabled) and the location of fine-grained ingress policies.
  - All subcommands accept `--json`.

- **Inbound event narration**: inbound GitHub, Slack, ntfy, and webhook events emit a transcript line naming the surface and event (for example `[GitHub] PR #42 (owner/repo) opened -> agent triggered`) before the event is dispatched to the orchestrator. Companion and internal sources are excluded to prevent self-narration loops.

## Internal

- Architecture gate detects import cycles (Tarjan SCC over the import graph, proven against an injected scratch cycle) and enforces 8 directional layer rules. The conversation/system-message-router cycle is genuinely broken via the runtime barrel.
- Auth listener behavior is pinned by 18 live tests: default login rate limit (five 401s then 429), proxy-spoofing posture, empty-password handling.
- Golden-frame harness pins four renderer surfaces (shell footer, context meter, markdown transcript, panel workspace) with committed snapshots. Regeneration is byte-for-byte stable; a missing golden fails instead of regenerating; `GOODVIBES_UPDATE_GOLDENS=1` is the only write path.
- CLI management helpers deduplicated into `management-utils.ts`; `openBrowser` extracted to a shared utility.
- Websocket reconnect test deflaked with a deadline poll.
