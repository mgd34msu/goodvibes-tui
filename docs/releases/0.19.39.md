# GoodVibes TUI 0.19.39

## Changes

- Updated `@pellux/goodvibes-sdk` to `0.25.16`.
- Picked up SDK Cloudflare operational-token creation fixes for documented permission names, `Write`/`Edit` variants, and account/zone resource scoping.

## Notes

No TUI route contract changed in this release. Existing Cloudflare onboarding and `/cloudflare` flows continue to call the SDK daemon APIs; the SDK now creates operational tokens more reliably for Queues, Secrets Store, R2, DNS, and Zero Trust Access selections.
