# Release 0.18.21 (2026-04-16)

## Wave 3a / Tier 2 TUI UX Consistency Infrastructure (I5)

This release completes the final item from Wave 3a: selection gutter and filter input label conventions for list-based panels.

## Changes

### I5: Selection gutter in ScrollableListPanel

`ScrollableListPanel` gains an opt-in `protected showSelectionGutter = false` flag. When set to `true` in a subclass, `renderList()` post-processes each item line after `renderItem()` returns:

- Selected row: prepends `▸ ` (2 columns, info color, bold) at the start
- Unselected rows: prepends `  ` (2 spaces) to maintain alignment
- Line width is preserved (the last 2 cells are dropped)

This is off by default to avoid altering the visual layout of panels that already have their own selection indicators (e.g. `buildPanelListRow` with `marker`, or panels with icon-based row prefixes).

### I5: Filter input label conventions in SearchableListPanel

`SearchableListPanel` gains `protected buildFilterInputLine(width, label, focused)`, which replaces each panel's bespoke `buildSearchInputLine` calls with a consistent convention:

| State | Rendered format |
|---|---|
| `focused = true` | `[Filter] query_` (active, bold, cursor) |
| `focused = false` | `Filter: query` (dim, no cursor) |

The `label` parameter defaults to `'Filter'`; subclasses may pass any label (e.g. `'Search'`, `'Query'`).

The method delegates to `buildSearchInputLine` from `polish.ts`, passing `active: focused`.
