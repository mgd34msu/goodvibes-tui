# GoodVibes TUI 0.24.0

Fourth best-in-class program release: the engineering-task backlog closed, crash durability made real, and the composer brought to readline parity.

## Changes

- **Composer editing**: coalesced undo/redo (`Ctrl+Z` / `Ctrl+Shift+Z`, cursor restored), a 32-entry kill ring (`Ctrl+K`/`Ctrl+U` kill, `Alt+D` kill word forward, `Ctrl+Shift+Y` yank, `Alt+Y` yank-pop with emacs invalidation), Unicode word navigation (`Alt+B`/`Alt+F`), and a line-count indicator inside the prompt border. `kill-to-start` owns `Ctrl+U`; `clear-prompt` moved to `Alt+U`. A defaults-collision lint prevents any two actions from sharing a chord.

- **Transcript search**: `n`/`N` next/previous match in locked search mode, a `(wrap)` marker on the match count when navigation wraps, and the bindings documented in both help overlays. Activation is `Ctrl+F`.

- **Crash durability**: an append-only transcript journal (fsync per record) fills the gap between 60-second snapshots. A SIGKILL at any moment loses at most the in-flight write. Replay is wired into every resume seam: command resume, `Ctrl+R` crash recovery, and panel resume.

- **Push notifications**: turns that run longer than `behavior.notifyAfterSeconds` (default 60, 0 = off) fire a desktop notification and any configured webhook on completion or failure. Notification text is metadata only. Conversation content can never leak.

- **One-key retry**: after a turn error, `r` re-submits through the shared failover snapshot path (never a duplicate user message) and `m` opens the model picker. The exhausted-chain notice states plainly that `r` reuses the same provider.

- **`/health term`**: terminal-capability posture (the real term-caps probe) joins the doctor surface.

- **Command grammar**: conventions enforced by a live-registry lint test; `settingssync`/`profilesync`/`workplan` renamed to `settings-sync`/`profile-sync`/`work-plan` (old names remain as aliases).

## Internal

- Architecture gate: Tarjan SCC import-cycle detection plus 8 directional layer rules; the conversation/system-message-router cycle is genuinely broken.
- Golden-frame renderer harness with regen-stable committed snapshots; missing goldens fail CI.
- Release pipeline: warn-only live verifier in validation, a release-blocking macOS smoke job for darwin-arm64 binaries, and all six gates running locally pre-tag.
- ANSI-aware width padding in diff headers, progress rows, and panel spinners; auth listener pinned by 18 live behavioral tests; whole-suite single-process run verified clean.
- Inline terminal images canned by owner decision: images render as `[image N]` slugs identically in every terminal.
