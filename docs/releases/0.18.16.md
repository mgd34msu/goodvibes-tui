# 0.18.16: Test + architecture remediation, SDK 0.18.36 bump

**Released**: 2026-04-16
**Type**: Patch (bug fixes + dependency bump)

## Summary

0.18.15 left three issues unaddressed that this release closes:

1. Five `resolveToolLLM` tests failing because the `tools.llmEnabled` gate (added in SDK 0.18.30) defaulted to `false` and test helpers did not opt in
2. One `GC-ARCH-001` domain boundary contract test failing because two domain files were deleted in 0.18.15 but the `DOMAINS` array still listed them
3. `src/renderer/settings-modal.ts` violating the 800-line architecture cap at 844 lines

Also bumps the SDK dependency 0.18.33 → 0.18.36, pulling in four patch releases.

## What changed

### TUI

- `src/test/helpers/test-managers.ts`: `createTestManagers()` now sets `tools.llmEnabled: true` by default
- `src/runtime/store/domains/domain-read-matrix.ts`: `DOMAINS` reduced to `['panels', 'ui-perf']`, matching the files that actually exist after the 0.18.15 deletions
- `src/renderer/settings-modal-helpers.ts`: new file, 122 lines; contains 10 helpers extracted from `settings-modal.ts`
- `src/renderer/settings-modal.ts`: 737 lines (was 844); imports the helpers
- `docs/foundation-artifacts/*`: regenerated against SDK 0.18.36
- `package.json`: version 0.18.15 → 0.18.16, SDK dep 0.18.33 → 0.18.36

### SDK changes picked up (0.18.34 → 0.18.36)

- Daemon shutdown symmetry (stop() awaits all services started during start())
- RuntimeEventBus.emit snapshots listener set before dispatch
- SessionManager atomic write (tmp + fsync + rename)
- HttpListener RateLimiter TTL + LRU + periodic sweep, stop() clears interval
- `fetchWithTimeout` utility applied to github/ntfy/slack/gemini integrations
- `resolveHostBinding` honors configured port under all three hostModes
- `resolveDaemonFacadeRuntime` prefers constructor-injected `port`/`host` over configManager lookups

## Verification

- `bun run test`: 437 test files, all pass
- `bun run architecture:check`: passes (296 non-test source files, all under caps)
- `bunx tsc --noEmit`: clean

## Migration

None. All changes are backward-compatible.
