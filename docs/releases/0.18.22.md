# GoodVibes TUI 0.18.22

**Release date**: 2026-04-16
**Type**: Wave 3b / Tier 2 TUI UX Consistency — Panel Migration Batch

## Summary

Migrates 7 BasePanel-direct panels to `ScrollableListPanel<T>`, bringing the total
across both Wave 3a and 3b to 17+ migrated panels. Also restores 8 section-title
strings dropped during prior migrations, fixing regressions in 5 test files.

All panels that could not be cleanly expressed as `ScrollableListPanel<T>` are kept
as BasePanel with documented rationale.

## Migrated to ScrollableListPanel<T>

| Panel | Item type | Key decisions |
|-------|-----------|---------------|
| `HooksPanel` | `HookEntry` | `Recent Activity` + `Authoring` labels in footer; empty state shows extra context via `header` param |
| `McpPanel` | `McpServerSecurityEntry` (derived via `ReturnType`) | `MCP posture` label in header; no named export for item type |
| `ApprovalPanel` | `ApprovalRow` (const tuple) | `Approval posture` + `Selected Lane` labels in header |
| `SecurityPanel` | `TokenAuditResult` | Governance + threat lines in header; attack path in footer |
| `ServicesPanel` | `ServicePanelEntry` | `r`/`t` key overrides; loading early return before `renderList` |
| `SubscriptionPanel` | `SubscriptionRow` | Full `handleInput` override (`ArrowUp`/`ArrowDown`); logout confirm preserved |
| `TasksPanel` | `RuntimeTask` | `!readModel` early return; summary block in header |
| `IncidentReviewPanel` | `FailureReport` | `Action Rail` label added to footer |
| `CommunicationPanel` | `CommunicationRecord` | `Communication posture` label in both posture arrays |

## Kept as BasePanel

| Panel | Reason |
|-------|--------|
| `PolicyPanel`, `OrchestrationPanel`, `MarketplacePanel`, `SchedulePanel` | Uses `resolveScrollablePanelSection` (report-style, no single item list) |
| `MemoryPanel`, `KnowledgePanel` | Same — report-style section scroll |
| `RemotePanel` | Dual-mode: connections vs. contracts — two incompatible item types |
| `ProviderHealthPanel` | Raw escape sequences + `setInterval` + async refresh |
| `PanelListPanel` | Category headers interspersed; `fixedLines`, `canRenderNow()`, `reportRenderDuration()` |
| `SkillsPanel` | `resolvePrimaryScrollableSection` with `fixedLines`; `canRenderNow()`, `reportRenderDuration()` |
| `SessionBrowserPanel` | `resolveScrollablePanelSection` + `setInterval` refresh timer |

## Test regression fixes

Section-title strings from `PanelWorkspaceSection { title }` were rendered as visible
text in the old architecture but lost when panels migrated to flat `header`/`footer`
arrays. Fixed by adding explicit label `buildPanelLine` entries:

- `'Approval posture'` and `'Selected Lane'` in `ApprovalPanel`
- `'Communication posture'` in `CommunicationPanel` (both posture arrays)
- `'MCP posture'` in `McpPanel`
- `'Recent Activity'` and `'Authoring'` in `HooksPanel`
- `'Action Rail'` in `IncidentReviewPanel`
- Removed spurious `emptyMessage: intro` overrides from `HooksPanel`, `CommunicationPanel`, `McpPanel`
