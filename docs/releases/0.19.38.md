# GoodVibes TUI 0.19.38

## Changes

- Updated `@pellux/goodvibes-sdk` to `0.25.15`.
- Picked up the SDK Cloudflare bootstrap-token fix that resolves required permission groups with filtered lookups before falling back to broader catalog scans.

## Notes

No TUI Cloudflare route contract changed in this release. Existing onboarding and Cloudflare setup flows continue to call the SDK daemon APIs; the SDK now handles bootstrap-token permission-group resolution more reliably for account and zone scoped permissions.
